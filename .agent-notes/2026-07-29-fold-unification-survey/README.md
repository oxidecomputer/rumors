# The fold vocabulary of the skyline kernels

A read-only feasibility survey answering an owner question: the exposition
observes that every operation on a skyline is a constant number of folds, over
one skyline or two in parallel — so can the kernels actually factor into a few
fold definitions plus per-operator applications? The verdict is
FEASIBLE-PARTIAL, and it proposes a different cut than the original sketch. No
code changed; every claim cites the code it is checkable against.
